Generador de portal de documentos

Convierte todos los archivos de una carpeta en un solo HTML que funciona sin internet. No instala nada: todo ocurre en este navegador.

Este navegador es muy antiguo para el generador. Abre este archivo con Microsoft Edge o Google Chrome actualizados.

1Elige la carpeta

Cada subcarpeta será una sección del menú. Se leen .drawio, PDF, HTML, Word (.docx), Excel (.xlsx) y PowerPoint (.pptx). El navegador te pedirá permiso para leer y guardar en esa carpeta.

2Genera el portal

Opcional: ficha, orden y documentos pendientes (índice)

Crea una plantilla con todos los archivos, complétala en Excel y guárdala en la carpeta como indice.csv o indice.xlsx. Luego vuelve a generar. Las filas sin archivo aparecen como «Pendiente».

Elige una carpeta para empezar.

Formatos antiguos (.doc, .xls, .ppt) quedan solo para descargar: guárdalos como .docx/.xlsx/.pptx para verlos en el portal. Se ignoran archivos temporales (~$…) y carpetas que empiezan con _ o «.».
